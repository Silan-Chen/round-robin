# 新手指引人工验收清单

在 Chrome 或 Edge 中直接打开 `index.html`，按以下项目逐项检查。

## 首次访问

- [ ] 清除本页面的本地数据后刷新：没有历史比赛时，自动显示“3 分钟了解如何使用”引导。
- [ ] 引导显示五步，进度依次为 `1 / 5` 到 `5 / 5`。
- [ ] 第一步展示欢迎简介；后四步依次说明：新建比赛、选择对阵、填写双方比赛大比分、查看排名与本地保存位置。
- [ ] 第一步“上一步”不可用；中间步骤可前进和返回；第五步按钮为“开始使用”。

## 关闭与重开

- [ ] 点击“跳过指引”、右上角关闭按钮、遮罩空白处或按 Esc，均能关闭引导。
- [ ] 跳过或完成后刷新页面，不再自动显示引导。
- [ ] 首页、新建比赛页和比赛页页头均有“新手指引”按钮；点击后从第一步重新打开。
- [ ] 手动打开后关闭，不会清除或修改任何历史比赛、赛果、正在填写的姓名或比分。

## 大比分录入

- [ ] 录分区域标题和两个输入框均标明“比赛大比分”，并提示双方大比分不能相同。
- [ ] 输入相同的大比分并保存，会出现居中错误弹窗，且赛果、循环赛表格和排名均不变化。

## 布局与可读性

- [ ] 在约 375px 宽窗口中，弹窗未超出视口，内容可读，操作按钮可见且可点击。
- [ ] 引导为绿色帮助样式；错误弹窗仍为红色，二者语义可区分。
- [ ] 使用 Tab 键时，按钮可见焦点；Esc 关闭引导后，页面仍可继续操作。

## 兼容性

- [ ] 既有历史比赛用户打开首页时不会被自动引导打断。
- [ ] 禁用本地存储时，引导仍可在本次页面会话内关闭，且不妨碍新建比赛或查看错误提示。

## 移动端对阵与响应式布局

- [ ] 在 320px、375px、390px、430px 宽度下，页面没有页面级横向滚动；按钮、输入框和长中文姓名没有被裁切。
- [ ] 在 375px 宽度下创建 3 人比赛：显示与电脑端相同的循环赛表格；点击任一“待录入”单元格后可填写比分并保存。
- [ ] 在 320px、375px、390px、430px 宽度下，表格上方显示“左右滑动查看完整表格”；表格区域可独立横向滑动，页面本身不产生横向滚动。
- [ ] 在 5 人和 16 人比赛中，首列选手姓名在横向滑动时保持可见；待录入与已完成的单元格仍可点击或清除成绩。
- [ ] 在 16 人比赛与长中文姓名下，录分区域为单列、控件至少 44px 高，保存按钮完整可点击。
- [ ] 在 320px 宽度下，排名、错误弹窗和新手引导均可阅读和滚动；使用 Tab 时循环表格、主要按钮有可见焦点。
- [ ] 在 1024px 宽度下，循环赛表格与原有桌面端一致；从矩阵录分、清除成绩、查看推荐赛程和排名的原有流程可用。
- [ ] 在任一宽度刷新页面后，原有本地历史、赛果和排名仍可读取。
