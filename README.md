# 本地循环赛

一个无需安装、可直接在浏览器中使用的乒乓球循环赛记分工具。

它适合用一台电脑现场创建比赛、录入每场比赛的大比分，并实时查看循环赛表格、推荐赛程和排名。

## 功能

- 支持 3–16 名参赛者创建循环赛。
- 自动生成全部对阵和推荐赛程；人数为单数时会标记轮空。
- 可从循环赛表格或录分区录入、清除比赛结果。
- 根据胜场生成实时排名；同胜场时按相互交手结果处理，仍无法区分时会明确标记并列。
- 提供新手指引和适配手机的对阵录入界面。

## 使用

本项目没有构建步骤和第三方运行时依赖。

1. 双击 Windows 下的 [`打开循环赛.cmd`](./打开循环赛.cmd)，或直接用 Chrome、Edge 打开 [`index.html`](./index.html)。
2. 点击“新建比赛”，填写比赛名称和参赛者姓名。
3. 在循环赛表格中选择“待录入”，填写双方比赛大比分并保存。

## 数据保存与隐私

比赛数据只保存在当前浏览器的本地存储中，不会上传到服务器，也不会在设备或浏览器之间同步。

清除浏览器站点数据、使用无痕窗口，或更换浏览器/设备后，历史比赛可能无法恢复；请在需要时自行记录或备份赛果。

## 测试

自动化测试需要 Node.js 18 或更高版本：

```bash
node --test tests/core.test.mjs
```

人工验收项目见 [`tests/manual-checklist.md`](./tests/manual-checklist.md)。
